# Pentax K-1 Sync v3.0.0

专为 **PENTAX K-1（一代）** 打造的原生 Android 图传与水印客户端（Kotlin + Jetpack Compose）。

## v3.0.0 全部体验升级与修复
1. **彻底根治大图页底部按钮被截断**：废弃存在系统弹窗高度 Bug 的 `Dialog`，改用同窗口全屏覆盖层（`PhotoDetailOverlay`），严格遵循 `statusBarsPadding()` + `navigationBarsPadding()`，适配所有国产 ROM 手势导航栏。
2. **相册级大图交互**：支持 `HorizontalPager` 左右丝滑翻页 + 相邻预加载、双指缩放/双击放大、1× 状态下向下轻滑退出、单击隐藏工具栏、右上角顺手勾选加入批量下载。
3. **大图页实时单张下载与一键分享**：每个下载按钮直接显示实时进度百分比与绿色 `✓ 已存相册`，并支持通过 `FileProvider` 一键直达微信/小红书/Lightroom 分享。
4. **RAW+JPG 成对合并 & 图库密度切换**：支持将卡内同名 `RAW+JPG` 合并为单张卡片，并支持 `2列 / 3列 / 4列` 网格密度一键切换。
5. **水印配色与描述 100% 对齐 + 工坊全面升级**：新增「香槟金」共 5 种配色，7 款模板均忠实响应所选配色并具备明暗对比度自适应；新增**偏好持久化记忆**、**老镜头常用快捷标签**、**多图批量加水印**与**导出后一键分享**。
6. **传输与网络闭环**：新增全局悬浮传输进度胶囊、**一键断开热点并恢复 4G/5G 上网**、以及切回前台自动静默重连检测。
