# Pentax K-1 Sync v2.0.0 (K-1 一代专用现代安卓图传客户端)

专为 **PENTAX K-1（一代）** 打造的原生 Android 客户端（Kotlin + Jetpack Compose），全面采用暗房极简画廊视觉设计（致敬 Leica FOTOS / Hasselblad Phocus Mobile 暗调美学）。

## v2.0.0 重点升级
1. **全局暗房视觉重塑**：曜石黑画布 + 0.5dp 极细分割线 + 沉浸式全屏状态栏 + 极简底栏，彻底告别粗糙原生控件排版。
2. **大图详情页重构**：严格适配全屏与安全区域，照片占屏比提升至 75%+，缩放严格裁切不穿插，参数条与 RGB 直方图支持折叠展开。
3. **官方 PENTAX 几何矢量徽标 + 7 款精选水印模板**：自定义高分辨率 Canvas 矢量路径绘制官方 `PENTAX` 标志；内置经典双栏、极简白底、毛玻璃框、美术馆全白框、暗房黑金、35mm 胶片齿孔、无框极简角标 7 套模板。
4. **宾得 MakerNote / XMP / EXIF 三层镜头解析**：支持直接读取 K-1 JPG/DNG 内嵌镜头 ID 并自动识别常见宾得镜头；若无镜头信息（如老手动头或剥离 EXIF）则自动隐藏镜头栏，不再残留默认文字；同时修复竖拍照片方向自动旋转。
5. **遥控取景器放大防穿插修复**：Live View 容器严格裁切（`clipToBounds`），并升级支持 `1x / 2x / 4x` 放大 + 放大后自由拖动检焦。
